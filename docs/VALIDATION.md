# 开发基线验证记录

日期：2026-11-08。数据均为程序构造的测试样例，不包含真实学生作业。

## 已验证

Python 3.12干净虚拟环境按requirements.lock安装成功。执行 `python -m pytest -q`：**10 passed**。有1条Starlette TestClient使用httpx的弃用提醒，不影响本次测试；后续升级测试客户端时处理。

覆盖：

1. Bearer认证拒绝错误令牌。
2. 完整闭环：初稿→AI演示→人工确认错题→带提示订正→独立原题复测→审核后同类题验证。
3. 使用提示/答案后答对不算独立复测通过。
4. 跨作答analysis_id引用被拒绝，复测缺少任务被拒绝。
5. 图片真实字节验证、原图往返一致、同图去重、档案导出。
6. AI任务失败不会产生错题，错误响应不暴露供应商原始信息。
7. 报表日期范围及无效范围校验。
8. 未完成复测任务重复安排被拒绝。
9. AI编造原文引用被拒绝。
10. 演示模式不会生成伪造的同类题冒充真实结果。

其他静态检查：前端JavaScript通过node --check；Compose YAML可解析；OpenAPI 3.1自动导出；PostgreSQL建表DDL由ORM模型自动生成。
